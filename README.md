## 🌟 주요 특징 및 3차원 태그 분류

수집된 모든 기사를 **군종**, **산업/기술분야**, **방산기업** 3가지 축으로 정밀 분석하여 디스코드 카드에 태그를 부착합니다.

| 분류 축 | 포함 카테고리 | 예시 태그 |

| **🪖 군종 (Branch)** | 육군, 해군, 공군, 해병대, 우주/사이버, 국방부/방사청 | `[육군]`, `[공군]`, `[해군]` |
| **🔬 산업/기술분야 (Domain)** | 유도무기/방공(🚀), 항공/우주/드론(✈️), 기갑/화력/기동(🛡️), 함정/해양(🚢), 지휘통신/레이더(📡), 해외수출/계약(🌐), 국방정책/전력화(📢) | `[기갑/화력/기동]`, `[해외수출/계약]` |

## 🔑 API 키 및 웹훅 발급 가이드

### 1. 디스코드 웹훅 URL 발급 (초간단 30초)
1. 디스코드에서 알림을 받을 채널의 **`톱니바퀴 (채널 편집)`** 클릭
2. **`연동`** → **`웹후크`** → **`새 웹후크 만들기`** 클릭
3. 이름을 `국방방산알리미` 등으로 입력 후 **`웹후크 URL 복사`** 버튼 클릭

---

### 2. 카카오톡 '나에게 보내기' 연동 가이드 (1분 완성)
개인 카카오톡(나와의 채팅)으로 국방/방산 뉴스를 받고 싶을 때 사용합니다.

1. **[카카오 디벨로퍼스](https://developers.kakao.com/)** 로그인 후 **`내 애플리케이션`** → **`애플리케이션 추가하기`** (이름: `국방방산뉴스`)
2. **`앱 키`** 메뉴에서 **`REST API 키`** 복사
3. 좌측 **`카카오 로그인`** 메뉴:
   - 활성화 설정: **`ON`** 클릭
   - **`Redirect URI 등록`**: `http://localhost:5000/oauth` 입력 후 저장
4. 좌측 **`카카오 로그인` → `동의항목`**:
   - **`카카오톡 메시지 전송`** 항목의 [설정] 클릭 → **`이용 중 동의`** 체크 후 저장
5. **토큰 자동 발급 실행 (터미널)**:
   ```bash
   python kakao_auth_helper.py
   ```
   - 브라우저가 열리면 카카오 로그인 후 **`동의하고 계속하기`**를 누르면 끝!
   - `.env`에 키가 자동 저장되며, GitHub Actions용 `KAKAO_REST_API_KEY`, `KAKAO_REFRESH_TOKEN`이 화면에 출력됩니다.

---

### 3. 네이버 검색 API 발급 (NAVER API HUB)
네이버가 2026년 7월부터 검색 API를 **네이버 클라우드 플랫폼(NCP)의 NAVER API HUB**로 일원화하였습니다.

1. **[네이버 클라우드 플랫폼](https://www.ncloud.com/)**에 접속하여 네이버 계정으로 로그인합니다.
2. 상단 메뉴 **`Console`** (콘솔) 클릭
3. 좌측 전체 메뉴(All Services) → **`Application Services`** → **`NAVER API HUB`** (또는 `AI·NAVER API`) 클릭
4. **`Application 등록`** 버튼 클릭:
   - **Application 이름**: `국방방산뉴스`
   - **API 선택**: **`Search (검색)`** 체크 (뉴스/블로그)
   - **서비스 환경**: `Web 서비스 URL`에 `http://localhost` 입력
5. **`등록`** 완료 후 화면의 **인증 정보**에서 **`Client ID`**와 **`Client Secret`**을 복사합니다.

---

### 3. 디스코드 봇 토큰 발급 ([방법 2](#방법-2-상시-디스코드-봇-구동-슬래시-커맨드-양방향-모드) 전용)
1. **[Discord Developer Portal](https://discord.com/developers/applications)**에 접속하여 로그인합니다.
2. 우측 상단 **`New Application`** 클릭 후 이름 입력 (예: `DefenseNewsBot`)
3. 좌측 **`Bot`** 탭 이동:
   - **`Reset Token`** 클릭 후 생성된 **토큰(Token)** 복사
   - **`Privileged Gateway Intents`** 아래의 **`Message Content Intent`** 켜기 (`ON`)
4. 좌측 **`OAuth2` → `URL Generator`** 탭 이동:
   - **SCOPES**: `bot`, `applications.commands` 체크
   - **BOT PERMISSIONS**: `Send Messages`, `Embed Links`, `Attach Files`, `Read Message History`, `View Channels` 체크
   - 생성된 URL을 브라우저에 붙여넣어 내 디스코드 서버로 봇을 초대합니다.

## 🚀 방법별 사용 가이드

### [🌟 방법 1. 24/7 완전 무료 자동화 (GitHub Actions + 웹훅, 추천)](#-목차-table-of-contents)
> **내 컴퓨터 끄기 가능 / 서버 비용 0원 / 30분마다 GitHub가 알아서 수집 및 발송**

#### 1단계: GitHub에 저장소 푸시
```bash
git remote add origin https://github.com/내아이디/내저장소.git
git branch -M main
git push -u origin main
```

#### 2단계: GitHub Secrets 등록
1. 내 GitHub 저장소 페이지 상단의 **`Settings`** 탭 클릭
2. 좌측 메뉴 **`Secrets and variables`** → **`Actions`** 클릭
3. 초록색 **`New repository secret`** 버튼을 눌러 다음 값들을 추가:
   - **`DISCORD_WEBHOOK_URL`** (선택): [디스코드 웹훅 URL](#1-디스코드-웹훅-url-발급-초간단-30초)
   - **`KAKAO_REST_API_KEY`** (선택): [카카오 REST API 키](#2-카카오톡-나에게-보내기-연동-가이드-1분-완성)
   - **`KAKAO_REFRESH_TOKEN`** (선택): [카카오 Refresh Token](#2-카카오톡-나에게-보내기-연동-가이드-1분-완성)
   - **`NAVER_CLIENT_ID`** (선택): [네이버 Client ID](#3-네이버-검색-api-발급-naver-api-hub)
   - **`NAVER_CLIENT_SECRET`** (선택): [네이버 Client Secret](#3-네이버-검색-api-발급-naver-api-hub)

#### 3단계: 즉시 테스트 및 자동 실행 확인
- 저장소 상단의 **`Actions`** 탭 → 좌측의 **`국방·방산 뉴스 자동 알림`** → **`Run workflow`**를 누르면 즉시 1회 실행되어 디스코드로 뉴스가 전송됩니다.
- 이후에는 **컴퓨터를 꺼두셔도 30분마다 GitHub가 알아서 실행**합니다. (UTC 기준 매시 07분·37분)

### [🤖 방법 2. 상시 디스코드 봇 구동 (슬래시 커맨드 양방향 모드)](#-목차-table-of-contents)
> **대화형 명령어(`/뉴스_검색`, `/브리핑` 등) 지원 / 내 컴퓨터나 서버가 켜져 있어야 함**

#### 1단계: 가상환경 생성 및 패키지 설치
```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

#### 2단계: `.env` 환경 변수 설정
`.env.example` 파일을 복사하여 `.env` 파일을 만듭니다:
```bash
cp .env.example .env
```

`.env` 파일 편집:
```env
DISCORD_TOKEN=발급받은_디스코드_봇_토큰
CHECK_INTERVAL_MINUTES=15
MAX_ARTICLES_PER_CHECK=10
NAVER_CLIENT_ID=선택사항_네이버ID
NAVER_CLIENT_SECRET=선택사항_네이버Secret
TARGET_COMPANIES=현대자동차,LIG D&A,한화에어로스페이스,현대로템,LG이노텍,KAI
TARGET_COMPANY_MODE=prioritize
```

`TARGET_COMPANIES`를 설정하면 지정 기업을 우선 수집·발송합니다. 기본 `TARGET_COMPANY_MODE=prioritize`는 지정 기업 뉴스와 수주·입찰·양산·수출·예산 등 방산업계 핵심 뉴스를 함께 보냅니다. 지정 기업 기사만 원하면 `TARGET_COMPANY_MODE=only`로 설정하세요. 기업명은 `현대자동차`, `LIG D&A`, `한화에어로스페이스`, `현대로템`, `LG이노텍`, `한화시스템`, `한화오션`, `KAI(한국항공우주)`, `HD현대중공업`, `풍산`, `대한항공` 등 코드의 분류명과 동일하게 입력하세요.

한 번에 보낼 최대 기사 수는 `MAX_ARTICLES_PER_CHECK`으로 조절하며 기본값은 10입니다. GitHub Actions에서는 같은 이름의 Repository Secret을 추가하면 원하는 값(예: `8`, `10`)으로 바꿀 수 있습니다.

#### 3단계: 봇 실행
```bash
python -m src.bot
```
- 디스코드 채널에서 `/알림설정_채널 #채널명` 명령어를 입력하면 해당 채널로 자동 알림이 활성화됩니다.

## 🔒 보안 안내 (Public 저장소 주의사항)

> [!IMPORTANT]
> **저장소가 Public(공개)이어도 안전한가요?**  
> - **네, 안전합니다.** 디스코드 웹훅 URL이나 네이버 API 키를 **GitHub 저장소의 `Settings` → `Secrets`** 에 등록하시면 해당 값은 강력하게 암호화되어 외부에 일절 노출되지 않습니다.
> - **주의:** 파이썬 코드(`.py`)나 Git에 커밋되는 파일 내부에 키를 직접 적어서 푸시하지만 않으시면 됩니다. (`.env` 파일은 `.gitignore`에 의해 자동으로 커밋에서 제외됩니다.)
